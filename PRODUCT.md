# Mona Mayhem Product Brief

## Product vision
Mona Mayhem is a retro arcade GitHub Contribution Battle Arena. The app lets users compare the contribution activity of two GitHub profiles in a playful, game-like dashboard.

## Core experience
- Users enter or select two GitHub usernames
- The app fetches contribution data for each profile
- The experience compares their activity over time
- Results are displayed as a battle-style scorecard with arcade-inspired visuals
- The interface feels energetic, nostalgic, and readable

## Primary goal
Turn GitHub contribution comparisons into a fun, competitive visual experience that feels like a mini arcade game rather than a traditional stats dashboard.

## Project constraints
- Use Astro as the app framework
- Keep the codebase modular and understandable
- Prefer readable, maintainable implementation over clever abstractions
- Use Tailwind CSS and/or scoped CSS for presentation
- Preserve a retro arcade theme across the interface

## Success criteria
- Users can compare two GitHub contributors side by side
- Contribution data is surfaced clearly and convincingly
- The UI feels intentionally themed and polished
- Code remains easy to extend as the app grows
